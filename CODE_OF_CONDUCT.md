# Code of Conduct

This file is about **how we treat each other while collaborating** — not about how to
write code. For engineering guidance see [AGENTS.md](AGENTS.md) and
[CONTRIBUTING.md](CONTRIBUTING.md).

## The short version

Be respectful and constructive. Disagree about ideas, not people. That's most of it.

## Expected

- Give and receive technical criticism gracefully — critique the work, not the author.
- Assume good intent; ask before assuming malice or incompetence.
- Keep discussion focused on what's best for the project.

## Not tolerated

- Personal attacks, insults, or harassment of any kind.
- Publishing someone's private information without consent.
- Sustained disruption that derails technical discussion.

## Scope & enforcement

Applies to all project spaces — issues, PRs, discussions, and when representing the
project publicly. Project maintainers may remove content and, where necessary, restrict
participation by anyone violating these terms.

Report unacceptable behavior to the maintainers (repository owners). Reports are handled
confidentially and in good faith.
